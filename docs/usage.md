# 使い方ガイド

予選プール進行デジタル管理ツールの使い方です。大会当日、進行担当者が紙の進行用紙の代わりに、出欠・離席・対戦の呼び出し・結果をこのツールで記録します。入力した内容は自動的にstart.ggへ反映されます。

公開URL: https://skyinthehand.github.io/asynchronous-progression/

現在は開発中の試験版(β版)です。動作が変わったり不具合があったりする場合があります。

## 事前準備

大会の前に、管理者が端末ごとに行います。設定は端末ごとに保存されるため、**1台の端末で1つのプールを担当**します。

### 用意するもの

- **start.ggの開発者用トークン(Personal Access Token)**: 大会の情報の取得と、結果の送信に使います。管理画面に入るためのパスワードなどはありません。発行の手順は次の記事を参考にしてください。 https://yon4.hatenablog.com/entry/2023/07/15/151210

### 1. 担当するプールを設定する(管理画面「01 初期化」)

1. ツールを開き、進行ルールの「内容を確認しました」を押してから、進行画面の右上の「管理画面」を押します。
2. 「01 初期化」でstart.ggの開発者用トークンを入力し、「次へ」を押します。
3. 「大会一覧を取得」を押し、対象の大会を選びます。一覧に出ない大会は、大会スラッグ(大会URLの `start.gg/tournament/` の後ろの部分)を入力して「このスラッグで進める」を押します。過去に入力したスラッグは一覧から選べます。
4. イベント、フェーズの順に選び、担当するプールの「このプールを選択」を押します。総当り形式のプールは現在選べません。
5. その場で1回目の同期が行われ、「初回同期が完了しました」と出れば完了です。

### 2. 対戦台を設定する(管理画面「04 対戦台設定」)

このプールで使う対戦台(卓)を、start.ggに登録されている対戦台(station)の一覧から選びます。

- 使う卓にチェックを入れると、すぐに保存されます。
- start.gg側で対戦台を追加・変更したときは「対戦台一覧を再取得」を押します。
- 以前選んでいた番号がstart.gg側で見つからなくなった場合は「見つからない設定済みの番号」に表示され、個別に削除できます。

### 3. 進行ルールを確認する(管理画面「06 進行ルールの確認」)

進行担当者がツールを開いたときに最初に表示される「進行ルール」は、start.gg側の対象イベントの「Rules」欄の内容をそのまま取り込んだものです。

- 内容の編集はこのツールではできません。リンクからstart.ggの管理画面を開いて編集してください。次の同期でツールにも反映されます。
- Rules欄に緊急時の連絡方法が書かれていないと、画面上部に赤い警告が出ます。
- Rules欄の内容はすべて表示されるので、進行に関係のない内容は書かないようにしてください。

### 管理画面のその他の操作

| 項目 | 内容 |
|---|---|
| 02 対象プール | トークンを入力し直さずに、担当するプールだけを変更します |
| 03 同期状況 | 「データを再取得」で、自動同期(60秒ごと)を待たずにすぐ同期します |
| 05 連携トークン | 開発者用トークンだけを更新します(プールの選び直しは不要です) |
| 07 初期化(危険) | この端末のすべてのデータを削除します。端末を返却するときや、別の大会で使う前に使います |

## 対戦が始まるまでの準備

大会当日、プールの対戦を始める前に行います。

### 1. ツールを開いて進行ルールを確認する

1. ツールを開くと「進行ルール」が表示されるので、内容を確認して「内容を確認しました」を押します。確認するまで他の操作はできません。
2. 進行画面に入った後も、画面上部の「進行ルール」ボタンからいつでも見直せます。

### 2. 画面の見方

| 場所 | 内容 |
|---|---|
| 画面上部 | 同期の状態(「同期済み」「反映待ち N件」「同期不良」)、今すぐ同期するボタン、「進行ルール」、「管理画面」 |
| プールの情報 | クラス・形式・空き卓・進行(完了した対戦の数)・進行担当者 |
| 次の対戦 | 次に呼び出すとよい対戦と、「卓を選んで呼び出す」ボタン |
| 卓の状況 | 卓ごとに、使用中の対戦か「空き」かを表示します |
| タブ | 「ブラケット」(対戦カード)、「選手」(出欠・離席)、「次戦案内」(予選を終えた選手の次の対戦) |

### 3. 大会開始前の確認(初めてプールを開いたとき)

初めてそのプールを開くと「大会開始前の確認」が表示されます。進行担当者の記録 → 出欠確認 → 進行ルールの確認、の順に案内します。「キャンセル」で途中でやめることもでき、後から同じ操作を画面から行えます。

### 4. 進行担当者を記録する

プールの情報の「進行担当者」に名前を入力し、「担当者を記録」を押します。

### 5. 出欠を確認する

「選手」タブで、選手ごとに「出席」「未確認」「欠席」を選びます。欠席・離席中の選手がいる対戦は、次の対戦の候補に選ばれていない間、カードに「保留」と表示されます。

### start.ggでブラケットが開始されていない場合

start.gg側でプールの「Start Bracket」がまだ押されていない間は、画面に案内が表示され、結果入力・対戦台の設定・呼び出しができません。start.ggで「Start Bracket」を押してから、管理画面の「データを再取得」を押してください。

## 対戦が始まってからの操作

### 対戦の状態

対戦カードの状態は、start.ggと同じ順に進みます。

| 状態 | 意味 | start.ggでの表示 |
|---|---|---|
| 未着手 | まだ呼び出していない | — |
| 呼び出し中 | 選手を呼び出した。選手に通知が届く | 黄色 |
| 進行中 | 選手がそろい、対戦が始まった | 緑 |
| 完了 | 結果が確定した | — |

呼び出してから選手がそろったのを確認し、進行中にする流れです。

### 1. 次の対戦を呼び出す

1. 「次の対戦」の「卓を選んで呼び出す」を押します。
2. 「次戦候補」が開くので、使う卓を選び(選ばなくてもかまいません)、「呼び出す」を押します。対戦が「呼び出し中」になり、start.ggから選手へ通知が届きます。
3. 空いている卓が複数ある場合は、「呼び出す」を押すと次の候補が続けて表示されます。閉じると続きは表示されません。

- 候補は、空いている卓ごとに、プールの進行が早く進む順に選ばれます。離席中の選手がいる対戦は後回しになり、警告が表示されます。
- 配信台の対戦は配信側で進めるため、候補に出ません。

### 2. 状態・対戦台を変える

対戦カードをタップすると編集画面が開きます。

- 「状態」で「未着手」「呼び出し中」「進行中」を選びます。
- 「対戦台」で卓を選びます。呼び出し中・進行中の対戦が使っている卓は選べません。
- 状態と対戦台は、選んだ時点で保存されます。
- start.ggへ送信する前であれば、状態を前に戻せます(例: 進行中 → 呼び出し中)。送信した後は戻せません。

### 3. 結果を入力する

1. 対戦カードをタップして編集画面を開きます。
2. 「スコア」で、選手ごとに `DQ` `0` `1` `2` `3` `W` から1つ選びます。片方を選ぶと、もう片方は自動的に `0` になります。
3. 勝者が決まると、ボタンが「保存」から「結果を確定」に変わります。押すと結果が確定し、勝者・敗者が次の対戦へ自動的に進みます。

- `W` は、スコアは分からないが勝者だけ分かるときに使います(選んだ側が勝者になります)。
- `DQ` は失格です(選んだ側が負けになります)。
- 両者同時のDQ・W、同点では確定できません。
- 対戦相手のいない対戦(BYE)は「〇〇の不戦勝で確定」を押します。
- 結果を確定した直後に次戦候補があれば、「次戦候補」が自動的に開きます。

### 4. 結果を修正する

確定した結果は、対戦カードをタップしてスコアを選び直し、「修正を確定」を押すと直せます。修正した結果は、start.ggへ送信済みの場合もstart.ggへ反映されます。

次の場合は修正できません。カードに鍵マークが付き、鍵マークを押すと理由が表示されます。

- その対戦の勝者・敗者が出る次の対戦が、呼び出し中・進行中・完了になっている
- 配信台の対戦である

この場合は、start.ggの画面で直してください。直した結果は次の同期でツールにも反映されます。

### 5. 離席を記録する

「選手」タブで「離席する」を押し、必要なら理由を入力します。戻ったら「離席中 · 戻った」を押します。離席中の選手がいる対戦は、次の対戦の候補で後回しになります。

### 6. 予選を終えた選手を案内する

「次戦案内」タブに、予選を終えた選手の次の対戦相手と卓が表示されます。相手が決まるまでは「未確定」または「不明」と表示され、start.ggで決まると自動的に更新されます。

### start.ggとの同期

- オンラインの間、60秒ごとに自動的にstart.ggと同期します。すぐ同期したいときは、画面上部の同期の状態の横にあるボタンを押します。
- 入力した内容は先に端末に保存されるので、通信が切れても入力は続けられます。つながった時点で送信されます。
- start.ggの画面で入力・変更した結果や状態も、ツールに取り込まれます。
- アプリで入力した結果を送信する前に、start.ggで別の結果が入力されていた場合は、start.ggの結果を正とします。このとき「アプリで入力した結果を破棄しました」と表示されます。
- 「反映待ち N件」は、まだstart.ggに送れていない入力がある状態です。しばらくたっても減らない場合や「同期不良」と出る場合は、通信環境を確認してください。同期がしばらく成功していないと画面上部に通知が出て、「詳細」から失敗した理由を確認できます。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 進行画面に何も表示されない | 管理画面で担当するプールを設定したか確認してください |
| 進行ルールが表示されない | 管理画面でプールを設定したか、通信できているかを確認してください。一度取得できていれば、通信が切れても表示されます |
| 対戦カードをタップしても開かない | start.ggでブラケットが開始されていない、または鍵マークが付いている(修正できない)可能性があります |
| 対戦台が選べない | 管理画面の「04 対戦台設定」で卓を選んでください。呼び出し中・進行中の対戦が使っている卓は選べません |
| 次の対戦が表示されない | 呼び出せる対戦がない(前の対戦の結果待ち)か、空いている卓がありません |
| 「反映待ち」が減らない、「同期不良」と出る | 通信環境を確認してください。画面上部の通知の「詳細」で失敗した理由を確認できます |

## 現在対応していない機能

- **総当り形式のプール**: 管理画面でプールを選ぶときに選べません。
- **印刷用ページ**: 画面上部の印刷ボタンは現在使えません。
