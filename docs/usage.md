# 使い方ガイド

予選プール進行デジタル管理ツールの使い方をまとめたものです。大会当日の
現地で、進行担当者が予選プールの出欠・離席・対戦結果などを紙の進行用紙の
代わりにこのツールで記録するための操作手順を説明します。

対象URL: <https://skyinthehand.github.io/asynchronous-progression/>

このツールにはバックエンドサーバーがなく、入力内容はすべて操作している
端末のブラウザ内(IndexedDB)に保存されます。会場ネットワークが不安定でも
入力自体は止まらず、オンライン時に自動的にstart.ggへ反映されます。

## 全体の流れ

1. 大会前に、管理者がstart.ggのPersonal Access Tokenを使って対象の
   トーナメント/イベント/フェーズ/プールをこのツールに設定する
   (「事前準備」参照)。設定は端末ごとに行うため、**1端末につき1プール**を
   担当する運用になります。
2. 当日、進行担当者は一般モード(通常の画面)で出欠・離席・対戦結果を
   記録していく。
3. 入力内容は自動的に(オンライン時)start.gg側にも反映される。

## 注意事項の確認(起動時)

ツールを開くと、まず「注意事項」のダイアログが表示され、これを確認する
までは他の操作が一切できません。表示される内容は、対象イベントの
start.gg側「Rules」設定(プール進行注意事項)がそのまま使われます。

- 内容を確認したら「内容を確認しました」を押すと通常画面に進みます。
- 注意事項がまだ取得できていない場合は、その旨のメッセージが表示されます
  (管理画面での初期化が未完了、またはオフラインの可能性があります)。
- 通常画面に入った後も、画面上部の「注意書きを確認」ボタンからいつでも
  再確認できます。
- 注意書きに緊急連絡先の記載が確認できない場合は、画面上部に警告が
  表示されます(操作自体は止まりません)。start.gg側のRules設定に
  緊急連絡先を追記するよう、管理者に確認してください。

## 事前準備: 管理画面での初期化

画面右上の「管理画面」ボタンから入ります。初回はパスワード入力が必要です
(24時間操作がないと自動的にログアウトされます)。

### 1. 初期化(ログイン〜対象プール指定〜トークン設定)

1. start.ggのPersonal Access Tokenを入力し「次へ」。
2. トーナメント一覧が表示されるので対象を選択します。一覧に出ない
   非公開の大会などの場合は、大会URLのスラッグ(例:
   `start.gg/tournament/impact-major-4/...` の太字部分)を直接入力して
   進めることもできます。
3. イベント/フェーズを選択します。
4. 対象のプールを選択します。
   - **総当り(ROUND_ROBIN)形式のプールは現在選択できません**(動作確認が
     不十分なため、非対応としています。対応時期未定)。一覧上は
     「(総当り形式は現在非対応です)」と表示され、ボタンが押せません。
5. プールを選択すると、その場で1回目の同期が自動的に走ります。
   「初回同期が完了しました」と表示されれば一般モードにプールの内容が
   表示されます。

### 2. データを再取得

start.gg側でブラケットを「Start Bracket」した直後など、通常の自動同期
(最大60秒間隔)を待たずにすぐ最新状態を取り込みたいときに使うボタンです。
押すとその場で同期を1回実行します。

### 3. 対戦台

このプールで使う対戦台(卓)を設定します。対戦台はstart.gg側に登録済みの
「station」一覧から選ぶ形式です(自由入力ではありません)。

- 使用する台にチェックを入れると保存されます。
- 「対戦台一覧を再取得」でstart.gg側の最新のstation一覧を取り直せます。
- 過去に選択していたが、start.gg側でstationが削除されるなどして現在の
  一覧に見当たらなくなった番号は、「見つからない設定済みの番号」として
  別途表示され、個別に削除できます(データを黙って失わないようにする
  ためです)。

### 4. 対象プールのみ変更 / トークンのみ変更

- 「対象プールのみ変更」: 保存済みのトークンをそのまま使い、対象プールだけ
  変更できます(初期化のやり直しは不要)。
- 「トークンのみ変更」: Personal Access Tokenだけを更新できます。

### 5. 注意書き

現在start.ggから取得している注意書き(プール進行注意事項)を確認できます。
**本文の編集はこのツール内ではできません。** 「startgg側で対象イベントの
Rules設定を編集する」リンクからstart.gg側の管理画面に移動して編集して
ください。

## 大会当日: 一般モードでの進行操作

一般モードでは、担当プールの見出し(トーナメント名 - イベント名 -
フェーズ名 - プール名)の下に対戦カード一覧が表示されます。

初めてそのプールを開いたとき(オンボーディング未完了時)は、
「進行担当者→出欠確認→注意事項」の3ステップの案内ウィザードが自動的に
表示されます。各ステップは「キャンセル」でいつでも中断でき、強制では
ありません。

画面上部のツールバーから、以下のパネルをモーダルで開けます。

| ボタン | 内容 |
|---|---|
| 進行担当者 | このプールの現在の担当者名を表示・記録します |
| 出欠確認 | 選手ごとの出欠(未確認/出席/欠席)を記録します |
| 離席記録 | 選手の離席開始・終了と、任意の離席理由を記録します |
| 選手一覧 | 全選手の予選状況(予選中/予選通過)と、予選通過者の次戦案内をまとめて確認します |
| 次戦候補 | 空いている対戦台に対して、次に呼ぶべき対戦の候補を提示します(候補がない場合は押せません) |
| 印刷用ページ | 現在利用できません([現在対応していない機能](#現在対応していない機能)参照) |

離席中の選手がいる場合、離席記録パネルの選手名の横に離席開始時刻
(日本時間)と理由が表示されます。

## 対戦結果の入力

対戦カードをタップすると編集モーダルが開きます(確定済みで、かつ後続の
対戦が既に進行しているため修正できないカードはタップできません)。

- 未着手のカードは「進行中にする」ボタンで進行中の状態にできます
  (進行中のカードには「進行中」の表示が付きます)。
- 対戦台が設定されていれば、プルダウンからそのカードの対戦台を割り当てら
  れます。
- 片方の選手しかいない不戦勝(BYE)のカードは、専用の「〇〇の不戦勝で確定」
  ボタン1つで確定します。
- 通常のカードはスコア入力フォームが表示されます。各選手ごとに
  `DQ` / `0` / `1` / `2` / `3` / `W` のボタンから1つ選びます。
  - 片方を選ぶと、まだ何も選ばれていないもう一方は自動的に`0`が選ばれた
    状態になります(「結果を確定」を押すまでは未確定のままです)。
  - `W`はスコアが分からず勝者のみ分かる場合に使います(選んだ側が勝者に
    なります)。
  - 両者を同時にDQ・同時にWにすることや、同点での確定はできません(その
    場合はエラーメッセージが表示されます)。
- 確定済みの結果は、後続の対戦がまだ進行していなければ再度タップして
  修正できます。後続の対戦が進行している場合は「後続の対戦が進行している
  ため、この結果は修正できません」と表示され修正できません。

対戦カードの表示形式は、start.gg側のブラケット種別に応じて自動的に切り
替わります(勝者側・敗者側のあるトーナメント表 / 総当りなどの単純な
対戦表)。

## 次戦候補

「次戦候補」ボタンを押すと、空いている対戦台ごとに次に呼ぶべき対戦の
候補がモーダルで1件ずつ表示されます。

- 対戦台は任意で選び直せます(未入力のまま「対戦開始」を押すと、対戦台を
  割り当てずに進行中の状態にします)。
- 候補の対戦に離席中の選手が含まれる場合、警告として離席開始時刻と理由が
  表示されます(実際には呼んでもまだ試合を始められないことを進行担当者に
  伝えるためのものです。候補から除外はされません)。
- 「対戦開始」を選ばずにモーダルを閉じた場合、対戦の状態は変更されません。

## start.gg同期について

- オンラインである限り、60秒間隔で自動的にstart.ggへ同期します。オフライン
  から復帰した際にも即座に1回同期します。
- 同期に失敗しても、その場で入力を止めることはありません。入力内容は
  常に端末内に保持され続けます。
- 同期がしばらく成功していない場合、画面上部にスナックバー(帯状の通知)が
  固定表示されます。一定時間で自動的には消えないため、原因を確認して
  ネットワーク環境を見直してください。「詳細」を開くとエラー内容を確認
  できます。

## プレビューモード(ブラケット未開始)

start.gg側でそのプールのブラケットがまだ「Start Bracket」されていない
間は、画面全体が「プレビューモード」の表示(背景色の変化と案内バナー)に
なり、以下の操作ができません。

- 結果入力
- 対戦台の設定
- 「進行中」への変更

この場合はstart.ggの管理画面でブラケットを開始したうえで、管理画面の
「データを再取得」を押してください。取得が完了すると通常どおり操作
できるようになります。

## 現在対応していない機能

- **総当り(ROUND_ROBIN)形式のプール**: 動作確認が不十分なため、現在は
  非対応です。管理画面のプール選択時点で選べないようになっています。
  対応時期は未定です。
- **印刷用ページ**: 一般モードの「印刷用ページ」ボタンは現在使用できません
  (現状動作していないため無効化されています)。

## よくあるトラブルと対処

- **一般モードに何も表示されない**: 管理画面で対象プールの初期化(または
  対象プールのみ変更)が完了しているか確認してください。オンボーディング
  ウィザードが表示される場合は、一度キャンセルまたは完了させてください。
- **注意事項が取得できない**: 管理画面で初期化が完了しているか、
  ネットワーク接続を確認してください。オフラインでも一度取得できていれば
  端末内のキャッシュが表示され続けます。
- **対戦カードをタップしても編集モーダルが開かない**:
  1) プレビューモード(上記参照)である、
  2) 確定済みで後続の対戦が進行しているため修正不可、
  のいずれかの可能性があります。
- **対戦台の選択肢が出ない**: 管理画面の「対戦台」でstart.gg側のstationを
  1つ以上選択してください。
- **管理画面から24時間経つと自動的にログアウトされる**: 仕様です。再度
  パスワードを入力してください(初期化済みの設定は保持されます)。
